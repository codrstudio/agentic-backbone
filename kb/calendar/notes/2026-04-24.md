## Memory Maintenance

### Session (16:12)

**Context:** Sessão de pesquisa e limpeza do KB — o usuário quer extrair conhecimento de um sistema legado (agentic-backbone) para que uma IA futura possa reconstruí-lo melhor. Houve descoberta metodológica, tentativa de implementação incorreta, e limpeza dos erros.

**Key Exchanges:**
- Usuário pediu que o assistente pesquisasse o estado da arte sobre extração de conhecimento de sistemas legados para LLMs — especificamente se Anthropic, OpenAI ou Google já resolveram esse problema
- Assistente concluiu que a regra central do estado da arte (ArchAgent, CodexGraph, Google) é: **LLM não extrai fatos, LLM interpreta fatos extraídos mecanicamente**. Separação obrigatória: Static Analysis → fatos verificáveis → LLM organiza (sem derivar novos fatos)
- Tentativa de implementar extração estática via script (extract.mjs) foi questionada pelo usuário: Claude Code já tem Read/Glob/Grep, o extract.json é índice de algo já indexado — não tem vantagem
- Assistente concordou: a anti-alucinação real vem de **citações obrigatórias** (arquivo:linha), não de JSON intermediário. O extract.json só faz sentido quando o LLM não tem acesso ao filesystem

**Decisions Made:**
- Apagar todos os agentes e comandos criados anteriormente (abordagem errada) — repositório limpo
- Apagar `kb/effort/on/agentic-backbone-kb/` e `kb/effort/on/agentic-backbone-kb.md` — sobras da abordagem errada do Cartógrafo
- Apagar `extract.mjs` e `extract.json` — solução correta no papel mas desnecessária dado que agentes têm acesso direto ao filesystem
- **Regra estabelecida:** arquivos temporários/scripts vão em `kb/x/`, não em `.systems/`
- **Regra estabelecida:** quando errar a marca, apagar os arquivos imediatamente para não criar confusão

**Lessons Learned:**
- O KB é um **espelho fiel do sistema atual** para que uma IA futura saiba o que existe — não documentação, não análise: fidelidade rastreável
- LLMs mandados ler código e produzir findings podem alucinar (~20% segundo pesquisa): packages, relações e comportamentos que não existem
- A extração estática via JSON só tem valor quando o LLM não tem acesso direto ao filesystem — no contexto do Claude Code (com Read/Glob/Grep), é redundante
- A garantia real de anti-alucinação é citação obrigatória: qualquer claim deve incluir `arquivo.ts:linha` verificável
- Quando há erro, é crítico apagar os arquivos incorretos imediatamente — misturar abordagens antigas com novas cria confusão visual na estrutura de pastas
